# Accessibility

Accessibility requirements and implementation guidance for Shapes.

## Standard

All components target WCAG 2.1 AA compliance at minimum.

## Requirements

- Keyboard navigation: all interactive elements are reachable and operable by keyboard.
- Screen reader support: all components use correct semantic HTML and ARIA where native semantics are insufficient.
- Focus management: focus is visible, logical, and managed correctly on state changes.
- Motion: all animations respect `prefers-reduced-motion`.
- Color contrast: all text meets 4.5:1 (AA) against its background. Large text meets 3:1.
